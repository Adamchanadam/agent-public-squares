收到邀請

你收到 APS 協作邀請：讓本機 AI 代理帶你加入。

邀請人已經建立了一個共用 Google Drive 資料夾。你要做的不是研究命令，而是在自己的電腦上接好這個項目，之後就可以說 check Drive 收到對方交接。

你需要先準備三件事

  • 邀請人分享給你的 Google Drive 共用資料夾，而且你能在自己電腦上看到它。
  • 邀請訊息裏的項目代號。這個代號必須和邀請人一致。
  • 邀請訊息裏指定給你的 agent id。每個人填自己的，不要填對方的。
不要複製邀請人電腦上的本機路徑。Google Drive 在每部電腦上的路徑可能不同。你要用自己電腦上看到的共用資料夾路徑。
請把這個共用資料夾設為可離線使用。在 Windows 下，到 Google Drive 的目標資料夾，按右鍵，選 顯示其他選項，再選 離線存取，最後選 可離線使用。

把這段貼給本機 AI 代理

在你的本機項目資料夾打開 Codex、Claude Code 或同等 AI 代理，貼上整段：

我收到一個 Agent Public Squares 協作邀請。請在目前本機項目資料夾，按這頁指引帶我加入：
https://adamchanadam.github.io/agent-public-squares/docs/guides/aps-ai-agent-install.html

你要先讀完整頁面，再檢查目前資料夾是否適合安裝。任何會安裝套件、寫入檔案、修改設定或寫入共用 Drive 資料夾的步驟，先列出將會做甚麼，等我確認後才執行。Google Drive 本機路徑、項目代號、我的 agent id 由我提供；項目代號和 agent id 以邀請訊息為準。

AI 代理會帶你做甚麼

  1. 確認目前資料夾是不是你自己的本機項目資料夾。
  2. 確認共用 Google Drive 資料夾在你電腦上的路徑。
  3. 安裝或檢查 Agent Handoff Kit。
  4. 安裝 Agent Public Squares。
  5. 用邀請訊息裏的項目代號和你的 agent id 執行設定。
  6. 跑 npx aps doctor，確認你這一邊已接好。

成功之後怎樣用

當 AI 告訴你 doctor 通過後，你可以對它說：

check Drive

它會檢查共用 Drive 資料夾，整理對方交來的內容，先判斷是否足夠接手，再建議下一步。

卡住時不要自己刪檔

  • 看不到共用資料夾：先檢查 Google Drive 桌面版是否同步完成。
  • 項目代號不一致：回到邀請訊息，照原文填入。
  • AI 不認得 APS：請它重新讀本頁和 AI 代理安裝頁，並先檢查目前資料夾。
