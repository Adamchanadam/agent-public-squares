新手先用 AI 代理安裝，不用自己讀命令。

這裡把人類閱讀與 AI 代理操作分開。人類只要知道自己處於哪個情況，然後把指定頁面交給 Codex、Claude Code 或其他本機代理型 AI。APS 用共用 Google Drive 資料夾保存一對一 handoff packet，幫同一個項目的協作者與各自本機 AI 代理清楚交接任務。

你現在是哪一種情況？

第一次自己設置

我想在自己的項目安裝 APS

人類版新手頁。它只教你複製一段 prompt 給本機 AI 代理，讓 AI 帶你完成安裝、檢查，並在邀請協作者前先建立項目共同簡報。

 給 AI 讀

AI 代理安裝操作頁

Codex、Claude Code 這類本機 AI 代理應讀這一頁。裏面有完整檢查清單、命令順序、確認邊界與錯誤處理。

 被人邀請加入

我收到 APS 協作邀請

如果有人已經邀請你加入項目，從這頁開始。你一樣可以把 prompt 交給本機 AI 代理處理。

最快路徑

如果你不想分辨太多，直接把這段貼給本機代理型 AI：

請在目前本機項目資料夾，按這頁指引帶我安裝和設定 Agent Public Squares：
https://adamchanadam.github.io/agent-public-squares/docs/guides/aps-ai-agent-install.html

你要先讀完整頁面，再檢查目前資料夾是否適合安裝。任何會安裝套件、寫入檔案、修改設定或寫入共用 Drive 資料夾的步驟，先列出將會做甚麼，等我確認後才執行。Google Drive 本機路徑、項目代號、我的 agent id 由我提供。

安裝成功後，第一步是請 AI 建立項目共同簡報，先定好共同目標、參與者、角色、第一輪分工、不可做的事和驗收標準，再邀請協作者。示範人名不可當作固定預設；實際參與者和 agent id 由用戶提供或確認。

安裝後日常怎樣叫 AI？

  • 要看整體交接狀態，說 Check APS。AI 會按需檢查收件、發件、協作對象、下一步與風險摘要；它只整理本機已同步資料，不會自動派工，也不會背景自動監察。
  • 要查看對方有沒有新交接，說 check Drive。
  • 要交給指定協作者，說「用 APS 交給指定協作者」。AI 應先整理交接內容和風險，等你確認後才寫入共用 Drive 資料夾。

為甚麼要分人類頁和 AI 頁？

  • 人類新手不需要先理解 npx、doctor、init、peer add。
  • 本機 AI 代理需要完整規格，否則容易在錯誤資料夾或錯誤 Drive 路徑動手。
  • 安裝套件、寫入設定、寫入共用 Drive 資料夾前，仍要由用戶確認。
