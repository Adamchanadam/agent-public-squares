🚀 公開入口

把一段工作交給協作者，讓雙方 AI 接得住。

Agent Public Squares（APS）是 group project 的交接工具，不是你的目標本身。要交接時，最穩定的說法是直接告訴本機 AI：「用 APS 把這段工作交接給誰」。AI 會整理草稿、等你確認、再寫入共用 Drive，讓對方 AI 接手判斷。

📋 第一次使用：先讓 AI 接好工具

如果這個項目還未接好 APS，或已接好但要更新到新版，在你的本機工作目錄打開 Codex 或 Claude Code，貼上整段：

請在目前本機工作目錄，按以下頁面完成 Agent Public Squares（APS）安裝、加入或升級：

https://adamchanadam.github.io/agent-public-squares/docs/guides/aps-ai-agent-install.html
📌 你要確認三件資料：Google Drive 同步到本機的位置或 AI 建議的 APS 交換區、這個合作項目的 APS 合作目錄名稱、你自己的用戶名稱。若你收到邀請，還要照抄一次加入邀請碼。AI 會問你，不需要你事前填表。

🗺️ 宏觀流程

這張圖用 Adam 和 Jay 作示範，講清一次交接怎樣閉環：先建立共同基準，再發正式交接；Jay 用 check Drive 判斷能否開工，交接期間可用 APS Live 對齊，最後回到正式紀錄收結。

🔎 這張圖只講大局。這裏用 Adam 邀請 Jay 作示範，方便分清兩邊；正式邀請會產生一次加入邀請碼，Jay 用自己的電腦加入，用戶名稱由本人確認。交接時，Adam 不應只說一般工作安排，而應明確說「用 APS 把這段工作交接給 Jay」。AI 會整理交接草稿，Adam 確認後才寫入 APS，Adam 再人手通知 Jay。Jay 的 AI 透過 check Drive 讀到交接後，會判斷可開工、要澄清，還是要退回補資料。交接期間可用 APS Live 看階段與即時對齊；正式狀態仍以 Drive 內 packet、outbox 與 ack 為準，最後由同一條交接線 revise、回覆或 close 收結。

✅ 這條路適合誰？

適合

你用 Codex、Claude Code 或同等本機代理型 AI；它能讀寫目前項目資料夾、能執行命令、能讀網頁。

不適合

普通網頁聊天 AI，若不能操作你的本機工作目錄，就不能直接替你安裝。它最多只能解釋步驟。

⚠️ 不是全自動。AI 會帶你做，但安裝套件、寫入設定、寫入共用 Drive 資料夾之前，都應先列出計劃並等你確認。

🔎 APS 解決甚麼問題？

你要把一部分項目任務交給指定協作者時，最穩定的入口是明確提 APS，例如：「請用 APS 把這段工作交接給 Jay，先整理草稿，等我確認後才寫入共用 Drive。」這樣說，是為了讓 AI 走 APS 交接流程，而不是一般聊天式工作安排。AI 會先整理可核對的交接草稿，等你確認後才寫入 APS。對方收到人手通知後，在自己的項目資料夾說 check Drive，AI 就能讀到交接內容、版本與已讀狀態。若想看整個 APS 項目的收件、發件、協作對象、下一步與風險摘要，可以說 Check APS；若交接期間要看階段、跟協作者即時對齊、收回饋或補資料，打開 APS Live 交接追蹤工作台。這些入口只整理本機已同步資料和用戶確認的動作，不是自動派工，也不是背景自動監察。

  • 同一個項目可以有多位協作對象。
  • 每一次交接仍是一對一，不是群發。
  • 第一位用戶安裝後，AI 應主動建立「共同目標與分工」，先做到夠安全開始：共同目標、自己的用戶名稱、第一個可做小步、明顯不可做事項和最小驗收方式先清楚；其他角色、第一輪分工、邀請對象或詳細驗收可以先標為「未定」。
  • 交接期間可以打開 APS Live 交接追蹤工作台看階段、對齊下一步、收回饋和補資料；正式進度仍以 Drive 內正式交接紀錄為準。
  • APS 不會自動通知對方，也不會自動打開對方的 AI。
  • AI 會生成可複製的通知文字，由你貼到 WhatsApp、Email 或平常使用的通訊工具。

📌 目前狀態

公眾可用前期測試版

本頁對應版本是 @adamchanadam/aps@0.2.35。它已可用於受控實際試行，但仍不應承諾為不可中斷、不可出錯的生產級工具。每個真實項目第一次使用時，AI 應先帶用戶建立夠安全開始的共同目標與分工；示範人名不可當作固定預設，實際參與者和用戶名稱由用戶確認。共同目標與分工確認後，再按狀態保存、邀請協作者、讓已加入的協作者確認，或整理第一輪交接草稿。

如果你是第一次安裝，直接使用上方 prompt。安裝成功後，AI 應主動接上共同目標與分工流程，不需要你先學 APS 命令。若你是收到別人的 APS 邀請，請看 收到邀請的加入頁。若你想看完整教學入口，前往 教學中心。
