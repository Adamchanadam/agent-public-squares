用一句話，請本機 AI 代理帶你安裝 APS。

Agent Public Squares 讓兩邊的 AI 透過共用 Google Drive 資料夾交接工作。你不需要先學命令；最簡單的方法，是把下面這段話貼給 Codex、Claude Code 或其他能操作本機資料夾的 AI 代理。

先複製這一句

在你想安裝 APS 的本機項目資料夾打開 Codex 或 Claude Code，貼上整段：

請在目前本機項目資料夾，按這頁指引帶我安裝和設定 Agent Public Squares：
https://adamchanadam.github.io/agent-public-squares/docs/guides/aps-ai-agent-install.html

你要先讀完整頁面，再檢查目前資料夾是否適合安裝。任何會安裝套件、寫入檔案、修改設定或寫入共用 Drive 資料夾的步驟，先列出將會做甚麼，等我確認後才執行。Google Drive 本機路徑、項目代號、我的 agent id 由我提供。
你要準備三件資料：Google Drive 同步到本機的共用資料夾路徑、這個合作項目的項目代號、你自己的 agent id。AI 會問你，不需要你事前填表。

這條路適合誰？

適合

你用 Codex、Claude Code 或同等本機代理型 AI；它能讀寫目前項目資料夾、能執行命令、能讀網頁。

不適合

普通網頁聊天 AI，若不能操作你的本機資料夾，就不能直接替你安裝。它最多只能解釋步驟。

不是全自動。AI 會帶你做，但安裝套件、寫入設定、寫入共用 Drive 資料夾之前，都應先列出計劃並等你確認。

APS 解決甚麼問題？

你這邊的 AI 做到一半，要交給另一個人、另一部電腦或另一個 AI 接手時，APS 會把「你接手吧」變成一份可核對的交接包。對方只要在自己的項目資料夾說 check Drive，AI 就能讀到交接內容、版本與已讀狀態。

  • 同一個項目可以有多位協作對象。
  • 每一次交接仍是一對一，不是群發。
  • APS 不會自動通知對方，也不會自動打開對方的 AI。
  • AI 會生成可複製的通知文字，由你貼到 WhatsApp、Email 或平常使用的通訊工具。

目前狀態

公眾可用前期測試版

目前公開版本是 @adamchanadam/aps@0.2.16。它已可用於受控實際試行，但仍不應承諾為生產級工具。每個真實項目第一次使用前，都應先做一次測試交接，確認雙方 Google Drive 同步與 AI 設定正常。
