# Agent Public Squares v0.2.16 — Strict handoff intake

This release candidate adds a stricter formal handoff path for one-sentence APS requests.

## Highlights

- `aps publish --strict-handoff` now blocks formal packets that are missing the shared goal, both-side task boundaries, handoff point, requested action, evidence, or risks.
- The APS skill now treats "please hand this to Jay" as a guided intake flow, not a direct-send command.
- README and public teaching pages now explain that AI should build a handoff definition card, fill reliable gaps, and ask only the few questions needed before publishing.
- Regression coverage now includes strict handoff failure and strict handoff success cases.

## Still out of scope

APS still does not auto-notify people, wake another AI, run a background watcher, create group chat, or send one packet to multiple recipients. It remains a human-in-the-loop shared Drive handoff protocol.
