## Agent Public Squares v0.2.33

這版是 v0.2.32 後的公開邊界修正版，目標是讓 PUBLIC 只保留新手與公開產品頁，將維護者、QC 與 plans 真源移回 OPS 私有治理區。

### 主要更新

- PUBLIC `docs/` 只保留公開入口、教學頁與圖片資產。
- 維護者 HTML、QC HTML 與 APS Live planning spec 移回 OPS 私有治理目錄，不再出現在 GitHub Pages 或 npm package 的公開文檔面。
- npm package 不再打包維護者 QC 檔、examples 或整個 `docs/` 目錄，只保留 runtime、公開教學、release notes、skill、protocol、README 與 LICENSE。
- APS skill 不再指向 PUBLIC `docs/plans/`；維護者治理資料被明確標為不隨 runtime package 發佈。

### 驗收狀態

- PUBLIC regression 已新增檢查，阻止 `docs/maintainers`、`docs/qc`、`docs/plans` 回到公開文檔面。
- `npm pack --dry-run --json` 應只包含公開 docs、runtime、skill、protocol 與 release notes。

### 使用邊界

這版不新增 APS runtime 能力。正式 APS 進度仍以共用 Drive 內的 packet、outbox 與 ack 為準；APS Live 只作即時核對、階段引導與例外協調。
