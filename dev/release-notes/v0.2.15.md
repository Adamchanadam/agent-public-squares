# Agent Public Squares v0.2.15 — Project Dashboard / Daily Index

This build promotes the Project Context Index work into a daily, human-readable project view for non-technical users.

## Status

- Release target: `@adamchanadam/aps@0.2.15`.
- Previous public npm latest before this release: `@adamchanadam/aps@0.2.14`.
- Previous GitHub Latest release before this release: `v0.2.14`.
- No Hub migration required. Existing packets, lanes, ack files, peer cards, configs, and context logs remain compatible.

## What Changed

### Project Context Index regression baseline

`npm test` now runs `dev/qc/check_context_index.cjs`. The regression creates disposable local fixtures and checks context schema, source references, stale-source warnings, newer packet version detection, conflict markers, forbidden task-management fields, unsafe file references, invalid agent ids, exact packet source-ref idempotency, and generated HTML output.

### Packet-derived context entries

`npx aps context add --from-packet <packet_id> --version <n>` can append a background-only entry to the executing agent's own `_context/from_<agent_id>/context.log.md`.

This is deliberately limited:

- It writes only the local agent's context log.
- It does not write packet, outbox, ack, consume, close, revise, or withdraw state.
- It deduplicates by exact source reference, so `v1` is not confused with `v11`.

### Read-only Daily Index HTML

`npx aps dashboard` generates `_context/dashboard.html` as a read-only Project Dashboard / Daily Index.

The dashboard reads locally synced packet / outbox / ack / peer cards / context log and shows:

- what this agent still needs to check
- outgoing handoff state
- suggested reading
- project background
- peer state
- risks and unresolved items

`npx aps context html` can generate `_context/overview.html` with the same daily view when the local agent identity is available.

### Google Docs extension-reading links

Context source refs may include `url:https://...` values. The generated HTML renders these as external reading links, including Google Docs links.

URL refs are not treated as locally verified execution truth. Packet / outbox / ack remain the authority for work state.

### Explicit ack state wording

The dashboard may reflect explicit synced state such as:

- `尚未看到對方標記處理`
- `對方已標記處理（ack 已記錄）`
- `已收結`
- `已撤回`

It must not infer that the recipient saw a notification merely because a file exists in the shared Drive folder.

### Daily receive alias

`npx aps check-drive` aliases the existing receive route and starts with a human daily brief. It may show Project Context Index as background only before the received handoff summary.
