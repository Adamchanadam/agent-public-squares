## Agent Public Squares v0.2.26

這版修正 AI 代理安裝、加入與升級 prompt 的使用體驗。原本的公開 prompt 會讓 AI 在安裝套件、寫入檔案、修改設定或寫入共用 Drive 前反覆停下確認，實測會令新手安裝太煩瑣，也會拖慢整個 session。

### 主要更新

- 公開 README、首頁、教學中心、加入邀請頁、onboarding walkthrough 和 AI 代理安裝頁，已改成一次性計劃確認。
- AI 現在應先做只讀檢查，列出判斷結果、會安裝或更新甚麼、會寫入或使用哪些本機與共用 Drive 路徑，以及不會做的事。
- 用戶確認一次後，AI 應按該範圍連續完成 npm install、APS init 或 APS upgrade、設定寫入與 doctor，不要每個命令重複問。
- 仍保留安全邊界：遇到計劃外路徑、刪除或覆寫既有 APS 資料、提交、推送、發佈、改權限、費用操作或代發外部訊息，AI 必須停下再問。
- `peer invite` 產生的可轉發邀請 prompt 也同步到新版口徑，避免受邀者加入時再次遇到逐步批准式體驗。

### 驗收狀態

- PUBLIC `npm test` 已通過，包含公開安裝指引安全邊界、邀請 prompt 可複製性、邀請碼接受與重用阻擋、多 peer 一對一 packet、共同目標收件摘要與 APS Live 本地矩陣回歸。
- `node --check bin\aps.js` 與 `node --check dev\qc\check_context_index.cjs` 已通過。
- `git diff --check` 已通過。
- 全部 PUBLIC `README*.md` 與 `docs/**/*.html` 已掃描；舊安裝／升級逐步批准句不再出現。仍保留正式交接草稿在寫入共用 Drive 前要由用戶確認的安全邊界。

### 使用邊界

APS 仍是前期測試版。這版改善新手安裝與升級流程的順暢度，但以下項目仍未完成：

- 未完成真兩機／獨立網絡 APS Live 證明。
- 未完成真人零知識 UAT。
- 未完成外部通知送達證明。

因此，`APS Live` 目前仍應理解為「本機已驗收、可進入真兩機驗收」的功能，不應描述成已證明可靠的跨機即時協作。
