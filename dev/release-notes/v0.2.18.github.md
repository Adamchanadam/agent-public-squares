# Agent Public Squares v0.2.18 — Check APS status surface

This release adds a new APS status entry point: `Check APS`.

## Highlights

- Adds `npx aps check-aps` for whole-project APS status.
- Shows incoming handoffs, sent handoffs, collaborators, and risks in a conversation-readable summary.
- Refreshes `_context/dashboard.html` on demand.
- Keeps `check Drive` as the receive-side inbox check.
- Narrows natural-language routing so generic `status`, `check`, `交接包`, and `收工` do not accidentally trigger APS.
- Updates README, public docs, APS skill guidance, roadmap, QC standards, and sync registry.

## Still out of scope

APS still does not auto-notify people, wake another AI, run a background watcher, create group chat, or send one packet to multiple recipients. `Check APS` is an on-demand local status view, not proof that another person received a notification.
