## Agent Public Squares v0.2.25

這版補上 APS 邀請碼旅程、共同目標收件摘要，以及 APS Live 首次使用與狀態刷新矩陣，讓新協作者加入和第一輪交接更穩定。

### 主要更新

- 邀請新協作者改用一次加入邀請碼。發起方用 `peer invite` 產生唯一邀請碼和可轉發邀請；受邀者在自己電腦自選 APS 名稱加入。
- 邀請碼會記錄為 `open`，加入後改為 `accepted`；同一邀請碼不能重用，project 不一致也會阻擋。
- 同一 APS project 可有多位 confirmed peer，但每份 packet 仍只發給一位接收者。
- `check Drive` / `inbox` 會把 `shared_goal_and_roles` 顯示為共同目標與分工確認，而不是普通任務；摘要不足時會明確要求讀完整 packet。
- `Check APS` 在 confirmed peer 存在但未見共同目標基準時，會自動生成 APS Live 頁，並把 `共同基準` 標成需處理，而不是誤判為已完成。
- APS Live 會區分無基準、共同目標草稿未確認、正常交接、補資料退回、舊頁刷新、同身份視窗、錯 project room 和 Drive 同步延遲形態。
- 公開 README、安裝／加入／升級指引、skill wording、APS Live 規格和 QC 文件已同步到這條新路徑。

### 驗收狀態

- PUBLIC `npm test` 已通過，覆蓋邀請碼接受與重用阻擋、多 peer 一對一 packet、共同目標收件摘要、APS Live 無基準首用、共同目標草稿、正常交接、補資料退回、舊頁刷新與 active packet 一致性。
- `node --check bin\aps.js` 與 `node --check dev\qc\check_context_index.cjs` 已通過。
- `git diff --check` 已通過。

### 使用邊界

APS 仍是前期測試版。這版可以讓你用 npm 安裝後做進一步雙機驗收，但以下項目仍未完成：

- 未完成真兩機／獨立網絡 APS Live 證明。
- 未完成真人零知識 UAT。
- 未完成外部通知送達證明。

因此，`APS Live` 目前應理解為「本機已驗收、可進入真兩機驗收」的功能，不應描述成已證明可靠的跨機即時協作。
