# Agent Public Squares v0.2.14 — Readable Packet UX Root-Fix

This release fixes two new-user UX defects found during a two-folder self-UAT run against the real shared Drive Hub.

## Fixes

- **Readable packet summaries.** Notifications and inbox rows now skip label-only section headings such as `Common goal:` and show the first useful action line instead.
- **Closed-packet status.** `status --packet-id` now reports a closed packet successfully with `已收結` instead of failing after the sender closes the packet.
- **Human-readable inbox report.** `inbox` now leads with what the other side sent, what they are asking you to do, whether you should act yet, and the next step. Packet id / version / path remain available under technical details.

## Compatibility

- No Hub migration required.
- Existing packets, lanes, ack files, peer cards, and configs remain compatible.
- The 0.2.13 onboarding model remains unchanged: three-question `init`, explicit `--items`, peer invite via `peer add`, and shared-folder default `Agent_Public_Squares`.

- Isolated inbox-report regression confirmed `inbox --all` shows `對方交了甚麼`, `對方請你做`, `我該不該做`, and `建議下一步` before technical details.
