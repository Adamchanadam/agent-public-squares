## Agent Public Squares v0.2.37

這版修補 v0.2.36 外部 full audit 找到的相鄰流程錯位：當發起方收到協作者的正式回覆 packet 時，`Check APS` 和 APS Live 不應再把它顯示成「對方查看 / 處理」或「可開工判斷」。那是發起方要審閱回覆、決定是否標記已處理、要求修訂或收結原交接的階段。

### 主要更新

- `Check APS` 會把回覆型收件顯示在「檢查回覆 / 收結」階段。
- 「對方查看 / 處理」階段在回覆型收件下會顯示已完成，而不是目前位置。
- 需要跟進清單會把回覆型 packet 標成「待審閱 / 收結」，不再標成「可開工」。
- APS Live 新增回覆審閱狀態，第一屏會提示先讀回覆正文、審閱風險與未決事項，再決定是否標記已處理或收結。
- PUBLIC regression 已加入 sender 收到 reply 後的 CLI 主流程、結論、action list 和 APS Live stage 覆蓋。

### 驗收狀態

- Source syntax、PUBLIC regression、npm pack、installed smoke、外部 readback 和 Adam / sandbox 真實工作區重裝後的外部 full audit 仍須在正式發布流程逐項跑完。
- 這版修正的是 v0.2.36 audit 中已發現的產品語意錯位，不等同已完成真實人類 UAT、獨立兩機同步證明、APS Live transport 證明或外部通知證明。

### 使用邊界

正式 APS 進度仍以共用 Drive 內的 packet、outbox 與 ack 為準；APS Live 只作即時核對、階段引導與例外協調。回覆內容必須先讓用戶看見，再讓用戶決定標記已處理、要求修訂或收結。
