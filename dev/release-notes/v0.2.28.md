## Agent Public Squares v0.2.28

這版針對非技術新手的安裝、加入與升級入口做收斂。重點是把用戶端 prompt 壓到最短，把詳細規則交回 AI-readable install page，讓本機 AI 代理讀頁後自行完成判斷、安裝、升級、doctor 與短格式回報。

### 主要更新

- README、公開入口頁、教學中心、加入邀請頁與 onboarding walkthrough 改用同一段短 prompt。
- `peer invite` 生成的可轉發邀請改用同一段短 prompt，同時保留 APS 合作目錄、邀請碼、Google Drive 共用資料夾名稱與邀請人等結構化欄位。
- AI 代理安裝頁明確成為詳細規則真源：用戶端 prompt 只需提供頁面網址，安裝、加入、升級、確認與收尾規則由頁面承載。
- 完成回報改為貼近 CLI 結果的短格式，避免 agentic AI 另創厚模板。
- QC fixture、UX transcript sample 與靜態 regression 已同步鎖定短 prompt，防止舊長 prompt 回流。

### 驗收狀態

- `node --check dev\qc\check_context_index.cjs` 已通過。

- 本地 tarball install、installed CLI `--help`、installed README / CLI / install HTML 短 prompt 內容檢查已通過。

### 使用邊界

APS 仍是前期測試版。這版清掉的是「非技術新手安裝文字太重、入口 prompt 太長、AI 讀頁後自行安裝 / 升級路徑不夠乾淨」這個入口問題。

以下外部 gate 仍未完成：

- 真人新手 UAT。
- 真 Drive timing 驗證。
- 真兩機／獨立網絡 APS Live transport 證明，特別是 peer join / leave / reconnect 與 A→B / B→A browser chat。
- 外部通知送達證明。
