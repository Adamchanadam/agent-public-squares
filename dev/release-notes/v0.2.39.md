## Agent Public Squares v0.2.39

這版補強 APS Live 在同一部本機瀏覽器內的真實傳輸驗收路徑。重點不是增加新口號，而是修正本輪驗收暴露的實際問題：雙頁未能互相識別、訊息沒有送達、離線待送草稿沒有在重連後補送，以及正式動作按鈕在瀏覽器驗收中缺少穩定定位。

### 主要更新

- APS Live 房間識別不再因 `live_focus` 不同而把同一個 APS 合作項目的兩個本機頁面分裂成不同房間。
- 同一瀏覽器的多頁測試加入本機後備識別，避免兩個分頁共用同一 `localStorage` 身分而被誤判為同一頁。
- APS Live 訊息派送會在偵測到對方頁面後重新沖刷待送草稿，覆蓋離線待送與重連補送情境。
- 清除對話改為頁內二段式確認，避免瀏覽器原生確認視窗阻塞自動驗收。
- 正式 consume、decline、close 動作按鈕加入穩定瀏覽器選擇器，讓本機瀏覽器證據可以逐一點擊驗收正式 UI 分支。
- `check_context_index` 回歸補上 APS Live 雙頁 peer detection、message dispatch、pending resend、clear conversation 和 formal action selectors 的產品級檢查。

### 驗收狀態

- PUBLIC regression 已通過，覆蓋 APS Live 本機雙頁 peer detection、訊息互傳、待送草稿重連補送、清除對話頁內確認，以及正式 action selectors。
- S320 browser evidence 已在本機 Chrome 工具中補齊 active packet fixture 的 consume、decline、close 按鈕點擊證據。
- 發佈候選驗收會再執行 source syntax、PUBLIC regression、npm pack 和乾淨安裝 smoke test，確認打包版本與已安裝行為一致。
- 這版證明的是本機瀏覽器與本機套件層的 APS Live 傳輸修補，不等同已完成真兩機可靠性驗收、真人 UAT、外部通知、目標工作區重裝或跨裝置 Google Drive 同步時序證明。

### 使用邊界

APS Live 可以作為交接期間的追蹤工作台與即時對齊頁，但正式狀態仍以 APS packet、outbox 和 ack 紀錄為準。任何 consume、decline、close 動作都應保持人類確認與正式紀錄讀回；瀏覽器內按鈕驗收只證明頁面分支可被觸發和追蹤，不代表對方已被外部通知或真實另一部電腦已同步完成。
