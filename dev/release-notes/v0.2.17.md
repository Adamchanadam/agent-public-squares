# Agent Public Squares v0.2.17 — Project brief onboarding

Status: release-ready source for `@adamchanadam/aps@0.2.17`.

## What changed

- Added an AI-led project kickoff brief as the required post-install step before inviting peers or sending first-round packets.
- The APS skill now asks the first user to confirm shared goal, participants and agent ids, roles, first-round split, forbidden actions, acceptance criteria, first invite target, and first handoff target.
- Example names such as `adam`, `jay`, `fanny`, and `jackie` are explicitly examples only. They are not product defaults, fixed roles, or hard-coded flows.
- The eight project brief fields are the minimum field set. AI agents may add project-specific fields such as deadline, priority, reference files, brand voice, approvals, compliance limits, output format, language, budget, or time limits without removing the core fields.
- README and public HTML now route new users through install -> project brief -> invite peer / first handoff.

## New-user effect

A first user can say:

```text
請先幫我建立這個 APS 項目的共同簡報，再邀請協作者。
```

The AI should draft or ask for only the missing essentials, let the user confirm the brief, then proceed to peer invite or first handoff.
