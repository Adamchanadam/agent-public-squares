# Agent Public Squares v0.2.15 — Project Dashboard / Daily Index

This release adds a read-only Project Dashboard / Daily Index on top of the Project Context Index work.

## Added

- **`aps dashboard`.** Generates `_context/dashboard.html`, a read-only daily view for what this agent needs to check, outgoing handoff state, suggested reading, background, peer state, and risks.
- **Context HTML daily view.** `aps context html` can generate `_context/overview.html` using the same daily view when local agent identity is available.
- **Google Docs reading links.** `url:https://...` context source refs render as external reading links, including Google Docs links.
- **Daily receive alias.** `aps check-drive` aliases the existing receive route and starts with a human-readable daily brief.

## Guardrails

- Packet / outbox / ack remain the execution truth.
- Dashboard and context HTML are read-only derived snapshots.
- Dashboard can reflect explicit synced `ack / close / withdraw` state.
- Dashboard must not infer that a recipient saw a notification from Drive file existence.
- `context add` writes only the executing agent's own context log and does not consume, close, revise, withdraw, or write packet / outbox / ack state.
