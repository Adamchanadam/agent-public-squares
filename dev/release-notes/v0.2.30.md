## Agent Public Squares v0.2.30

這版修正 APS 新手交接流程在真實 UAT 中暴露的幾個斷點：AI 代理只逐步推進但沒有大局觀、`check-aps` 流程位置容易被改寫、APS Live 入口不夠早出現、同一部電腦多個 APS 項目可能撞到同一個本機 Live bridge，以及正式工作包關閉後仍被錯誤視為進行中。

### 主要更新

- `check-aps` 現在以表格清楚顯示 APS 流程位置，並用明顯標記指出當前階段、下一步與 APS Live 是否建議打開。
- APS skill 與 bridge 規則要求 AI 在「繼續 APS 交接」、「看看現在去到哪一步」、「打開 APS Live」等情境先跑 `check-aps`，保留原本的流程位置表格，不再自行改寫成另一套狀態表。
- APS Live 入口改為在合適階段主動提供可點擊 `file:///...` 連結，同時保留本機檔案路徑作 fallback。
- APS Live bridge 改為按 APS 合作目錄推導本機 port，降低同一部電腦多個 AI project session 互相連錯項目的風險。
- APS Live formal-state 修正等待、已回覆、已收結、沒有進行中交接等狀態，避免在仍等對方處理時錯誤顯示「收結這條交接」。
- demo bridge、transcript matrix、flow map、UAT fixture 與 QC 覆蓋同步更新，保留今次北岸設計交接 UAT 的關鍵路徑。

### 驗收狀態

- 北岸設計 UAT 已跑完整 formal handoff lifecycle：共同目標確認、正式工作包、接收方回覆、發送方查收、雙方 close。
- 同機雙工作區驗收已覆蓋兩個代理角色互動，但真兩機、獨立網絡、真 Drive timing 與真人新手 UAT 仍屬外部驗收邊界。
- `node --check bin\aps.js` 已通過。
- `node --check dev\qc\check_context_index.cjs` 已通過。
- `npm test` 已通過。
- `git diff --check` 已通過；只有 Windows 換行提示。
- 發佈前 pack / install 驗收已確認 tarball 可安裝，installed CLI、`check-aps --demo-preview`、`live --demo-preview` 與 packed regression test 可執行。
- `npm audit --audit-level=high` 已通過，未發現 high 以上漏洞。

### 使用邊界

這版提升 APS CLI 與 APS Live 在普通用戶第一次交接流程中的引導能力，但不把 APS Live 當成正式資料真源。正式進度仍以共用 Drive 內的 packet、ack、outbox 記錄為準。APS Live 是即時核對與減少迷路的入口。
