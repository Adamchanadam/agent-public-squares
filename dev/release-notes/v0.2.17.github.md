# Agent Public Squares v0.2.17 — Project brief onboarding

This release improves the first-user journey after installation. A local AI agent now guides the first user to establish a shared project brief before inviting collaborators or sending the first APS handoff.

## Highlights

- Adds an AI-led project brief step after install and before peer invite / first handoff.
- Defines the minimum shared brief fields: common goal, participants and agent ids, roles, first-round split, forbidden actions, acceptance criteria, first invite target, and first handoff target.
- Clarifies that example names such as `adam`, `jay`, `fanny`, and `jackie` are examples only, not defaults or hard-coded roles.
- Allows project-specific extra fields such as deadline, priority, references, brand voice, approvals, compliance limits, output format, language, budget, and time limits.
- Updates README and public teaching pages so the new-user path is install -> project brief -> invite peer / first handoff.

## Still out of scope

APS still does not auto-notify people, wake another AI, run a background watcher, create group chat, or send one packet to multiple recipients. It remains a human-in-the-loop shared Drive handoff protocol.
