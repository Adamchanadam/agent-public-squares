## Agent Public Squares v0.2.32

這版是 v0.2.31 後的公開面清理版，目標是讓 GitHub、npm package、GitHub Pages 和維護者 HTML 的文字口徑一致，避免把內部驗收細節暴露給新手用戶。

### 主要更新

- README、首頁和版本標示同步到本頁 / 本包對應版本 `@adamchanadam/aps@0.2.32`。
- 清理 v0.2.31 release note 的內部驗收細節與過期發佈狀態字眼。
- flow map 的公開發佈讀回狀態改為分清已讀回版本與本版發佈後需重跑的讀回關口，並保留真人 UAT、真兩機與真 Drive timing 的外部邊界。
- 維護者 HTML 和治理 HTML 不再在瀏覽器裏自動拼出本機工作區路徑。

### 驗收狀態

- 本地發佈前檢查已覆蓋 GitHub Pages 對應 HTML、PUBLIC HTML 互鏈、圖片、GitHub repo 連結與 npm package 內容。
- 本地 package tarball 已可逐檔比對 PUBLIC 本機真源；外部發佈關口固定包括 npm、npx、GitHub release 與 GitHub Pages 讀回。
- 公開面痕跡掃描已覆蓋本機工作區路徑、內部驗收代號、過期發佈狀態與打包細節。

### 使用邊界

這版不新增 APS runtime 能力。正式 APS 進度仍以共用 Drive 內的 packet、outbox 與 ack 為準；APS Live 只作即時核對、階段引導與例外協調。
