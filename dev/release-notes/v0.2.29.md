## Agent Public Squares v0.2.29

這版修正 APS 安裝 / 升級完成後，AI 代理回報太長的問題。

v0.2.28 已經把入口 prompt 收短，並把詳細安裝 / 升級規則放到 AI-readable install page。實測發現：當本機 AI 代理讀不到該頁時，會改用本機 APS skill、setup dialogue、CLI 輸出與 doctor 結果自行整理，容易把備份路徑、TLS 讀頁失敗、handoff / log 更新和完整命令流水放進最終回報。

### 主要更新

- AI 安裝頁把「短完成回報」提升為完成合約，不再只是寫作建議。
- APS bundled skill 加入升級完成回報硬規則，作為讀頁失敗時的 fallback 真源。
- setup dialogue 加入同一個短完成回報 fallback。
- QC 加入對 HTML、skill、setup dialogue 的短回報規則檢查，防止厚回報模板回流。

### 預期完成回報

成功升級後，AI 代理應使用短格式：

```text
✅ APS 升級完成，doctor 預檢通過。
🚀 下一步:重新啟動 Claude Code 或 Codex，再在項目資料夾輸入「教我用 APS」。
APS 合作目錄：<名稱>；用戶名稱：<名稱>；doctor：通過。
```

備份路徑、TLS / 網絡讀頁失敗、`SESSION_HANDOFF.md`、`SESSION_LOG.md`、完整命令流水、npm 安裝細節和 skill 安裝目標，只在用戶追問或 doctor 失敗時補充。

### 驗收狀態

- `node --check dev\qc\check_context_index.cjs` 已通過。
- `npm test` 已通過。
- `git diff --check` 已通過；只有 Windows 換行提示。
- 發佈前 release QC 已確認 pack dry-run、真實 tarball、隔離安裝、installed CLI `--help`、installed HTML / skill / setup dialogue / QC 內容。
- 正式發佈後仍需讀回 npm、npx、GitHub release 與 remote refs。

### 使用邊界

這版只修正完成回報收斂與 fallback 規則。真人新手 UAT、真 Drive timing、真兩機 / APS Live transport、外部通知送達證明仍是外部 gate。
