## Agent Public Squares v0.2.34

這版修補兩個安裝實測暴露的公開包問題：npm package 內的 APS 初始化不應依賴 repo-only examples，並放寬 APS 合作目錄代號長度，讓真實項目 / 任務命名有足夠空間。

### 主要更新

- APS `bridge-pack` 與 `init` 改用 package 內的 runtime template：`resources/bridge-pack/aps-bridge.md.template`。
- npm package 繼續不打包 `examples/`，但會打包 Bridge Pack runtime template，避免已安裝 package 找不到 fixture。
- APS 合作目錄代號 `--project` 從最多 30 字放寬為最多 64 字；用戶名稱等身份欄位仍維持較短限制。
- CLI 錯誤訊息與新手引導明確說明：APS 合作目錄代號應用項目或任務命名，不要用人名或用戶名稱。
- README、shipped skill、setup dialogue 與公開安裝教學同步使用較真實的任務型例子，例如 `community_open_day_parent_notice`。

### 驗收狀態

- PUBLIC regression 覆蓋 64 字 APS 合作目錄代號可用、65 字會被拒絕，以及命名提示清楚區分項目 / 任務代號與用戶名稱。
- PUBLIC regression 覆蓋 packed npm tarball 安裝後的 `bridge-pack` 與 `init --dry-run`，避免只在 source tree 通過、npm package 失敗。
- `npm pack --dry-run --json` 應包含 `resources/bridge-pack/aps-bridge.md.template`，並仍排除 `examples/`、維護者 QC 與 private planning docs。

### 使用邊界

這版仍是受控實際試行用的前期測試版。正式 APS 進度仍以共用 Drive 內的 packet、outbox 與 ack 為準；APS Live 只作即時核對、階段引導與例外協調。
