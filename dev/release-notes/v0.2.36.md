## Agent Public Squares v0.2.36

這版候選版修補 APS 決策前證據不足的根因：AI 或 CLI 讀到交接正文、對方回覆、退回理由或 APS Live 待辦後，不能只給用戶一個判斷就要求決定。用戶在批准、審閱、退回、收結或交給本機 AI 整理前，必須先看見足夠的可讀內容和正式紀錄邊界。

### 主要更新

- `check Drive` 現在會在待處理交接內顯示可先閱讀的正文摘錄，並在有待處理收件時主動提供 APS Live 交接追蹤工作台路徑。
- `Check APS` 會在要求用戶作下一步決定前，顯示待查看交接的正文摘錄；不再把「AI 已讀」當成「用戶已看見」。
- APS Live 的正式動作卡會顯示交接正文、對方回覆或退回理由，再讓用戶考慮接受、退回或收結。
- `live-queue` 和 `Check APS` 的 Live 待辦摘要會顯示最近可讀對話，方便用戶知道本機 AI 將整理甚麼。
- `publish --dry-run` 和 `revise --dry-run` 會輸出發送前 / 修訂前確認卡，列明正文摘錄、正式寫入邊界和 dry-run 未寫入狀態。
- CLI help 已補上 `publish --dry-run`、`revise --dry-run` 和直接寫入命令的邊界提示，提醒新手主流程應先經 `check Drive` / `Check APS` / 本機 AI 看見證據。

### 驗收狀態

- PUBLIC regression 覆蓋回覆草稿正文在 `check Drive` 和 `Check APS` 內可見。
- PUBLIC regression 覆蓋多件 pending 交接時，每件都可顯示可讀摘錄，而不是只顯示數量。
- PUBLIC regression 覆蓋 APS Live 待辦最近對話、`live-queue` 摘要、正式動作卡正文 / 回覆 / 退回理由可見。
- PUBLIC regression 覆蓋 `publish --dry-run`、`revise --dry-run`、直接 CLI 寫入邊界與 lifecycle 命令讀回。
- 候選版仍需完成正式 release 前檢查：source syntax、source regression、npm pack、installed smoke、外部 readback，以及 Adam / sandbox 實際工作區重裝後的外部 full audit。

### 使用邊界

這份 release note 描述的是 v0.2.36 候選版內容，不等於已發布 npm、GitHub release 或 GitHub Pages。正式 APS 進度仍以共用 Drive 內的 packet、outbox 與 ack 為準；APS Live 只作即時核對、階段引導與例外協調。這版修正決策前可見證據與直接寫入邊界，不等同已完成真實人類 UAT、獨立兩機同步證明、APS Live transport 證明或外部通知證明。
