## Agent Public Squares v0.2.27

這版把邀請、加入、互邀、既有 APS 項目、第一次 Check APS、正式交接、check Drive、資料不足退回、revise 與 close 的單機產品流程整理成一致的候選發佈版本。重點不是新增複雜操作，而是收斂用戶旅程：用戶講目的，AI 做技術。

### 主要更新

- 邀請協作者統一為一個入口。無論用戶說「邀請協作者」、「邀請 Jay」，或 AI 內部使用 `peer invite`，都生成同一份可轉發的 `---✂️---` 邀請 template。
- 邀請碼只代表可以加入某個 APS 合作目錄，不代表受邀者用戶名稱，也不是另一個房間。受邀者在自己電腦決定自己的用戶名稱。
- 用語統一為本機工作目錄、APS 交換區、APS 合作目錄與用戶名稱，避免把本機 AI 工作資料夾和 Google Drive 內的 APS 合作目錄混在一起。
- `peer add` 與 `peer starter` 降為維護 / 兼容路徑；普通新協作者邀請不應把它們作為平等選項給非技術用戶。
- PUBLIC 新增 APS 全流程地圖與 APS UX Transcript 矩陣，作為產品旅程、第一屏 UX、fixture 證據與外部 gate 的可檢查真源。
- 新手非技術 UX 產品結果閘已加入 regression：目標是非技術用戶只用自然語言，也能由安裝或加入走到第一份正式交接、收件、補資料、修訂與收結。
- APS Live operation smoke 標準與本地證據已補入 QC：本地 CLI / localhost bridge 證明 formal APS 狀態不會被 Live 自動改寫，正式狀態仍要回到 terminal / local AI 經用戶確認。

### 驗收狀態

- PUBLIC `npm test` 已通過，包含邀請 UX、安裝 / 加入 / 升級 prompt、B-side invite fixture、第一次 Check APS / APS Live branches fixture、formal handoff cycle fixture、新手非技術 UX 產品結果閘、APS Live operation smoke anchor、strict handoff、共同目標收件摘要與 dashboard retirement regression。
- `node --check bin\aps.js` 與 `node --check dev\qc\check_context_index.cjs` 已通過。
- `npm pack --dry-run --json` 已確認 `0.2.27` 發佈包包含 regression 需要讀取的 PUBLIC QC JSON、PUBLIC QC HTML、APS Live QC 文件、release notes、docs、skills、examples 與 protocol resources。
- `git diff --check` 已通過；只有 Windows 換行提示。

### 使用邊界

APS 仍是前期測試版。這版把單機產品流程與發佈包完整性推到可驗收狀態，但以下項目仍未完成：

- 未完成真人新手 UAT。
- 未完成真 Drive timing 驗證。
- 未完成真兩機／獨立網絡 APS Live transport 證明，特別是 peer join / leave / reconnect 與 A→B / B→A browser chat。
- 未完成外部通知送達證明。

因此，`APS Live` 目前仍應描述為本地已驗收、可進入外部 gate 的候選能力，不應描述成已證明可靠的跨機即時協作。
