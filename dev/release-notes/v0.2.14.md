# Agent Public Squares v0.2.14 — Candidate (Readable Packet UX Root-Fix)

Local candidate on top of 0.2.13. Not published yet. This build fixes new-user UX defects found during S53 self-UAT and follow-up inbox-report regression:

1. Packet notifications and inbox rows no longer use label-only lines such as `Common goal:` as the summary.
2. `status --packet-id` now reports a closed packet successfully instead of failing after the sender has closed it.
3. `inbox` now shows a human-readable receive report before technical packet details, so a new user can see what the other side sent, whether to act yet, and the next step.

## What Changed

### Useful summary extraction

`bin/aps.js` now treats common body labels as section labels, not packet content. This covers English and Chinese labels including common goal, requested action, evidence, risks / open items, and their Chinese equivalents.

Result:

- Before: notification / inbox summary could show only `Common goal:`.
- After: notification / inbox summary shows the first useful action line, such as `1. Confirm the packet appears in Agent B inbox.`

### Closed-packet status

`status --packet-id` now allows lookup of an already closed own packet. Close / withdraw protection remains unchanged: the command still blocks operations that should not apply to closed packets, but read-only status can now report the final state.

Result:

- Before: status after close failed with `狀態查詢失敗: packet ... is already closed`.
- After: status after close exits 0 and reports `✅ 狀態: 已收結。原因: ...`.

### Human-readable inbox report

`inbox` now renders pending work as a receive report instead of starting with packet mechanics. It keeps the same protocol data, but changes the first-screen order:

- `🔎 收件總覽`
- `🔎 對方交了甚麼`
- `📌 對方請你做`
- `✅ 我該不該做`
- `🚀 建議下一步`
- `📄 技術細節`

Result:

- Before: `inbox` led with `packet id`, summary, item count, and packet path.
- After: `inbox` first explains the work in human terms, then leaves packet id / version / path under technical details for troubleshooting.
